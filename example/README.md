# Frosted UI Kit Example

This is the canonical interactive catalog for `frosted_ui_kit`. It demonstrates
the public widgets, responsive modal behavior, performance presets, RTL support,
large-text behavior, and selectable usage snippets.

Run it from this directory:

```bash
flutter pub get
flutter run
```

The package quick-start guide is available at
[`doc/FROSTED_QUICK_START.md`](../doc/FROSTED_QUICK_START.md).
